# Kit de propuestas — FlowData Solutions

Propuestas listas para responder en minutos en **Workana** (sirven también para Upwork, LinkedIn o mensajes directos).
Copiá la que corresponda, completá lo que está entre `[corchetes]` y **personalizá siempre la primera línea**: es lo único que el cliente lee antes de decidir si sigue.

> Si el cliente escribe con "tú" o "usted", adaptá el voseo: *necesitás → necesitas / necesita*, *mandame → envíame / envíeme*, *tenés → tienes / tiene*.

---

## Reglas de oro

1. **Respondé rápido.** Las primeras propuestas son las más leídas. Ideal: menos de 1 hora desde que se publica el proyecto.
2. **Primera línea = su problema, no vos.** Nunca empieces con "Hola, soy…". Empezá repitiendo lo que necesita con sus palabras.
3. **Pedí un archivo de ejemplo.** Te permite cotizar bien y demuestra que sabés de qué hablás.
4. **Mostrá un ejemplo concreto** del portafolio que se parezca a su pedido.
5. **Cerrá con una pregunta**, no con "quedo a disposición". Una pregunta invita a responder.
6. **Corto.** Entre 80 y 150 palabras. Si escribe un texto largo, el cliente no lo lee.
7. **Sin links ni datos de contacto en Workana, Fiverr y Upwork.** Nada de URLs (web, GitHub, Canva, Drive), mails, teléfonos ni redes: lo toman como contacto externo y pueden bloquearte. Nombrá el ejemplo y decí que está en la **sección Portafolio de tu perfil**; si piden más, mandá capturas por el chat de la plataforma. Los links de este kit son solo para **clientes directos** (LinkedIn, recomendaciones, mail).
8. **No inventes experiencia** ni clientes. Si te preguntan, contá que estás arrancando y mostrá el portafolio: la honestidad cierra más proyectos que una mentira que se descubre.

### Qué proyectos conviene elegir al principio
- ✅ Presupuestos chicos o medianos (USD 30–300), plazos razonables, descripción clara.
- ✅ Clientes con pocas propuestas recibidas (menos de 10–15).
- ❌ "Proyecto gigante por poca plata", "prueba gratis", pedidos de pagar fuera de la plataforma.

## 1. Limpiar u ordenar un Excel / base de datos

**Cuándo usarla:** "ordenar planilla", "limpiar base de datos", "unificar datos", "eliminar duplicados", "normalizar Excel".

```
Hola [nombre]: entiendo que tenés una planilla de [qué datos: clientes / ventas / stock] con [problema que mencionó: duplicados, formatos distintos, datos mezclados] y necesitás dejarla ordenada y lista para usar.

Así lo resolvería:
1. Reviso la planilla y detecto todos los problemas (duplicados, fechas y montos en distintos formatos, nombres escritos de varias formas, datos faltantes).
2. La limpio con Python y te entrego el archivo ordenado en Excel o Google Sheets.
3. Te paso un informe corto con todo lo que se corrigió.

Hice algo muy parecido con una planilla de ventas (datos ficticios): 77 filas desordenadas y 58 formas distintas de escribir los mismos datos, convertidas en una base confiable. Lo podés ver en la sección Portafolio de mi perfil ("Limpieza de una planilla de ventas").

Plazo: [2–3] días · Presupuesto: USD [40]

¿Me podés mandar un ejemplo de la planilla (aunque sean 20 filas) para confirmarte el alcance?
```

**Preguntas para afinar el presupuesto:**
- ¿Cuántas filas y columnas tiene, más o menos?
- ¿Es una planilla o son varias que hay que unir?
- ¿Para qué la vas a usar después? (reporte, importar a un sistema, análisis)
- ¿Hay reglas específicas? (formato de fecha, cómo nombrar productos)

## 2. Automatizar un reporte

**Cuándo usarla:** "automatizar reporte", "reporte mensual", "macro", "script Python", "automatizar Excel", "tablas dinámicas todos los meses".

```
Hola [nombre]: por lo que contás, hoy [quién] arma el reporte de [qué: ventas / gastos / stock] a mano [cada semana / cada mes] y querés que se genere solo.

Mi propuesta:
1. Analizo cómo armás el reporte hoy y qué datos usás.
2. Armo un script en Python (o automatización en Google Sheets, si preferís no instalar nada) que genera el reporte con un clic: totales, comparación con el período anterior y rankings.
3. Te entrego el reporte en Excel o en formato web, más una guía corta para usarlo.

Podés ver un reporte automático que armé (datos ficticios), con indicadores y conclusiones que se escriben solas, en la sección Portafolio de mi perfil ("Reporte de ventas automático").

Plazo: [5–7] días · Presupuesto: USD [120]

¿Me compartís un reporte de los que hacés hoy (puede ser con datos cambiados) para ver exactamente qué incluir?
```

**Preguntas para afinar el presupuesto:**
- ¿De dónde salen los datos? (Excel, Google Sheets, un sistema, exportación CSV)
- ¿Cada cuánto se arma el reporte y cuánto tiempo lleva hoy?
- ¿Quién lo va a usar? ¿Tiene Python instalado o preferís todo en Excel / Sheets?
- ¿Querés que llegue solo por mail?

## 3. Dashboard / tablero de indicadores

**Cuándo usarla:** "dashboard", "tablero", "Power BI", "Looker Studio", "visualizar datos", "KPIs". Power BI es tu fuerte: estos proyectos son prioridad.

```

1. Definimos juntos los 4–6 indicadores que más te importan.
2. Ordeno los datos de origen para que el tablero sea confiable.
3. Armo el dashboard en [Power BI / Google Looker Studio / Excel] (trabajo con Power BI en mi día a día como analista), con filtros por [fecha / vendedor / producto], que se actualiza cuando cargás datos nuevos.
4. Te muestro cómo usarlo en una llamada corta.

Podés ver un dashboard interactivo que armé (datos ficticios), con filtros, indicadores y comparación de períodos, en la sección Portafolio de mi perfil ("Dashboard de ventas interactivo").

Plazo: [5–10] días · Presupuesto: USD [150]

¿Qué decisiones querés tomar con este tablero? Con eso defino qué indicadores van primero.
```

**Preguntas para afinar el presupuesto:**
- ¿Dónde están los datos y cada cuánto se actualizan?
- ¿Cuántas personas lo van a ver? ¿Necesitan acceso con su cuenta?
- ¿Tenés preferencia de herramienta?

## 4. Carga de datos / asistente virtual

**Cuándo usarla:** "data entry", "carga de datos", "transcribir", "asistente virtual", "gestión de correos", "agenda".

```
Hola [nombre]: necesitás a alguien confiable que se encargue de [cargar datos de X a Y / gestionar correos y agenda / atender consultas] para liberar tu tiempo.

Cómo trabajaría:
• Te confirmo cada [día / tarea] lo que quedó hecho, así tenés todo bajo control.
• Uso planillas ordenadas y, cuando se puede, automatizo partes repetitivas para que el trabajo sea más rápido y sin errores.
• Trato toda la información con total confidencialidad.

Manejo Excel, Google Sheets, Gmail, Google Calendar y Notion.

Disponibilidad: [horario] · Tarifa: USD [8] por hora (o [X] horas al mes por USD [Y])

¿Cuántas horas por semana estimás que necesitás y con qué herramientas trabajan hoy?
```

**Tip:** si la tarea de carga es muy repetitiva, ofrecé automatizarla. Es un servicio mejor pagado y le ahorra plata al cliente.

## Mensajes para después de la propuesta

### Seguimiento (si no responde en 2–3 días)
```
Hola [nombre], ¿pudiste ver la propuesta? Si me pasás un ejemplo del archivo, te confirmo el alcance exacto sin compromiso.
```

### Cuando dice que es caro
```
Entiendo. Para ajustarme a tu presupuesto podemos empezar por lo más urgente: [versión más chica, ej. limpiar solo la planilla principal] por USD [monto menor]. Si te sirve, después seguimos con el resto.
```
No bajes el precio sin bajar el alcance.

### Cuando piden algo fuera de lo acordado
```
¡Buena idea! Eso no estaba en el alcance original, así que lo cotizo aparte: [descripción] por USD [monto] y [X] días más. ¿Lo sumamos?
```

### Al entregar (y pedir reseña)
```
¡Listo, [nombre]! Te dejo [entregables] y una guía corta para usarlo. Cualquier ajuste dentro de lo acordado, avisame y lo resuelvo.

Si quedaste conforme, me ayudaría muchísimo que dejes una reseña en [Workana]: estoy arrancando y cada opinión suma. ¡Gracias!
```

### Ofrecer el mantenimiento mensual
**Al entregar** (junto con el mensaje de entrega, o al día siguiente):
```
[Nombre], un detalle más: para que [el reporte / el dashboard] siga actualizado sin que tengas que ocuparte, ofrezco un mantenimiento mensual.

Por USD [150] por mes actualizo los datos cada semana, controlo que no haya errores y te dejo 3 horas para ajustes o indicadores nuevos. Sin permanencia: lo cancelás cuando quieras con 15 días de aviso.

Como recién terminamos el proyecto, el primer mes tiene 20 % de descuento. ¿Te interesa que lo arranquemos?
```

**Si duda:**
```
Te propongo probar un mes con el plan Esencial (USD 100): actualizo [el reporte] una vez por mes y te dejo 1 hora para ajustes. Si no le ves valor, lo cancelás y listo.
```

**Si el cliente avisa que algo dejó de funcionar** (y no tiene plan):
```
Lo reviso y te paso presupuesto para arreglarlo. Para que no vuelva a pasar, con el mantenimiento mensual (desde USD 100) quedaría cubierto: controlo los datos todos los meses y los cambios chicos van incluidos.
```

Detalle de los planes: [servicios/mantenimiento-mensual.md](../servicios/mantenimiento-mensual.md).

### Para recuperar un cliente (1 mes después)
```
Hola [nombre], ¿cómo viene funcionando [lo entregado]? Si te sirve, puedo automatizar [siguiente paso lógico, ej. el envío del reporte por mail] para que no tengas que tocar nada.
```
