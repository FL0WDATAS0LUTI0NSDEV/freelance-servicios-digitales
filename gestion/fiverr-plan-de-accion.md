### 2.5 Preguntas frecuentes
```
¿Podés conectarte a mi base de datos o SharePoint?
Sí. Contame cuál es la fuente y te lo confirmo antes de que compres.

¿El dashboard se actualiza con datos nuevos?
Sí. Queda armado para que lo actualices cuando cambien tus datos.

¿Necesito licencia Power BI Pro?
No para abrir el archivo .pbix en Power BI Desktop, que es gratuito. Para compartirlo en línea con Power BI Service, normalmente sí.

¿Me explicás cómo usar el dashboard?
Sí. Todos los paquetes incluyen una explicación de cada página, y el Premium una guía de uso.

¿Qué pasa si mis datos están desordenados?
El Básico parte de datos ya ordenados. Si hay que limpiarlos, el Estándar incluye la limpieza en Power Query. Mandame una muestra y te digo qué paquete conviene.

¿Atendés en inglés?
El servicio es en español.
```

### 2.6 Portfolio (3 proyectos de demostración)
Para los tres: cliente, precio y fechas **en blanco**; **sin links** en la descripción. Las imágenes están en `portafolio/capturas/` y `portafolio/capturas/fiverr/`.

**Proyecto 1 — Archivos:** `fiverr/video-dashboard.mp4`, `1-dashboard-interactivo.png` · **Gig relacionado:** Power BI
```
Dashboard de ventas interactivo para una distribuidora
```
```
Proyecto de demostración con datos ficticios.

Una distribuidora tenía un año de ventas en una planilla y armaba tablas dinámicas cada vez que necesitaba una respuesta. Armé un tablero web interactivo que se abre en cualquier navegador o celular, sin instalar nada:

• Filtros por período, provincia, vendedor, producto y cliente
• Indicadores: ventas, pedidos, ticket promedio y unidades, con variación contra el período anterior
• Gráficos interactivos: clic en un mes o un nombre para filtrar
• Tabla de detalle con búsqueda y exportación a CSV
• 12 meses y 293 ventas de ejemplo

Herramientas: Python (preparación de datos), HTML, CSS y JavaScript.
```

Reporte de ventas automático en HTML y Excel

**Proyecto 3 — Archivo:** `3-limpieza-de-datos.png`
```
Limpieza y orden de una planilla de ventas desordenada
```
```
Proyecto de demostración con datos ficticios.

Una planilla cargada a mano por tres vendedores tenía fechas en 4 formatos, clientes y productos escritos de muchas formas, montos con formatos mezclados, datos faltantes y filas duplicadas. No se podía saber cuánto vendió cada cliente.

Con un script en Python unifiqué fechas, nombres, productos, vendedores y provincias, convertí los montos a números, completé los faltantes calculables y eliminé duplicados: de 77 filas desordenadas a 70 filas confiables, con un registro de cada cambio.

Herramientas: Python (pandas), Excel.
```
