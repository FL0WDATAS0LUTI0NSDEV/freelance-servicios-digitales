## 4. Preguntas frecuentes
```
¿Qué pasa si mis facturas son escaneadas o fotos?
Se puede, pero lleva más trabajo (OCR). Mandame una muestra y te paso el precio.

¿Funciona con facturas de distintos proveedores?
Sí. Cada formato se configura una vez; el paquete indica cuántos formatos incluye.

¿Sirve para el Libro IVA Compras o Ventas?
Sí, para los dos. Las columnas se adaptan a lo que use tu contador.

¿Puedo usarlo todos los meses?
Sí. El Premium incluye el script para que lo repitas vos, o me lo encargás cada mes.

¿Mis facturas quedan seguras?
Sí. Solo las uso para tu pedido y las borro al terminar.

¿Atendés en inglés?
El servicio es en español.
```
